# Living India — SIH Prototype

A React + Vite frontend prototype for a community-driven digital heritage platform.

## Run
1. Install Node.js 18+
2. `npm install`
3. `npm run dev`
4. Open the local URL Vite prints.

## Prototype flows
- Explore/search heritage
- Heritage detail + Heritage DNA
- Community posts/comments actions
- Submit a heritage contribution
- Sign-in modal
- Heritage-at-risk dashboard
- Harappa interactive experience entry point

## Production next steps
Connect authentication, PostgreSQL/Supabase, object storage, moderation queues, expert verification, multilingual speech-to-text/translation, source provenance, analytics, and the Godot build.
